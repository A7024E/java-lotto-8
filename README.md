# java-lotto-precourse

## 로또 프로그램 소개
로또를 발매 이후 비교하여 당첨내역을 확인하고 수익률을 계산하는 간단한 로또 발매기 프로그램.

----
## 로또 프로그램 흐름

1. 구입금액 입력 (1000원 단위)
```
구입금액을 입력해 주세요.
8000
```

구입 금액 만큼 로또 출력 및 안내
```
8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

```

2. 당첨 번호 입력 ( 번호는 ,로 구분)
```
당첨 번호를 입력해 주세요.
1,2,3,4,5,6
```
3. 보너스 번호 입력

```
보너스 번호를 입력해 주세요.
7
```

4. 보너스 번호 입력 후 당첨번호 & 보너스 번호를 비교하여 당첨 내역 및 수익률 출력 (수익률은 소수점 첫재짜리까 표시.)
```
당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.



```

## 프로그램 흐름도

1. 구입 금액을 입력 받는다.
2. 구입한 수량과 발행된 로또 번호를 출력한다.
2. 당첨 번호를 입력 받는다.
3. 보너스 번호를 입력 받는다.
4. 당첨 번호와 보너스 번호를 이용해 로또 번호를 맞춘다.
5. 1등부터 5등까지 당첨 내역을 집계한다.
6. 당첨 통계를 출력한다.
7. 총 수익률을 계산하여 출력한다.

## 기능 구현 목록

### 입력 요구 사항

- [x] 로또 구입금액을 입력 받는 기능.
    - 1000원 단위로 입력 받는 기능.  
- [x] 당첨 번호를 입력 받는 기능.
    -  당첨 번호는 쉼표(,)를 기준으로 구분해서 입력받아야 한다.
- [x] 보너스 번호를 입력 받는 기능.

### 출력 요구 사항

- [x] 발행한 로또 갯수를 출력하는 기능.
    -[x] N개를 구매했습니다. 
- [x] 발행한 로또 번호를 출력하는 기능.
    - 로또 번호는 오름차순으로 출력해야한다.
- [x] 당첨 내역을 출력 하는 기능.
- [x] 총 수익률을 출력하는 기능 
  - 수익률은 소수점 둘째 자리에서 반올림하여 출력해야한다.
  - 수익률은 천단위부터 콤마로 구분하여 출력한다 예시 : (5,000원)
- [x] 예외 상황시 에러문구를 출력한다.
    - 에러 문구는 "[ERROR]" 로 시작해야 한다 
    - - `Exception`이 아닌 `llegalArgumentException`, `IllegalStateException` 등과 같은 명확한 유형으로 처리해야 한다.


### 공통 예외 상황
- [x] Null 값이나 빈칸을 입력한경우.
- [x] 공백을 입력한 경우.

### 금액 입력 예외 상황
- [x] 숫자가 아닌 문자를 입력한 경우.
- [x] 1000원 단위로 나누어 떨어지지 않을경우.
- [x] 1000원 보다 작은 금액을 입력할 경우.
- [x] 구입금액이 10만원 보다 클 경우.

### 로또 예외 상황
- [x] 로또 번호가 6개가 아닌경우.
- [x] 로또 번호가 1부터 45까지 범위가 아닌경우.
- [x] 로또 번호가 중복일 경우.

### 당첨 번호 예외 상황
- [x] 당첨 번호가 1부터 45까지 범위가 아닌경우.
- [x] 당첨 번호가 중복으로 입력 할 경우.
- [x] 정수외에 다른 문자열이 입력 할 경우.
- [x] 쉼표(,)를 연속해서 입력한 경우
- [x] 당첨 번호(로또 번호)를 쉼표(,)로 구분하지 않은 경우
- [x] 입력한 당첨 번호(로또 번호)가 6개가 아닌 경우

### 보너스 번호 예외 상황
- [x] 보너스 번호가 1부터 45까지 범위가 아닌경우.
- [x] 당첨번호에 포함된 번호로 입력 할 경우.
- [x] 정수외에 다른 문자열이 입력 할 경우.
